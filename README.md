# downloader

一个面向 Windows 的直接文件下载工具，适合 ISO、压缩包、视频素材等大文件。

## 功能

- 1、2、4、8、12 或 16 路 HTTP Range 并发下载
- 暂停后保留分块，下次从已有字节继续
- 网络错误自动重试，完成后先校验长度再合并
- 服务器不支持 Range 时自动改用单连接
- 自动跟随 3xx 镜像跳转，并识别链接中的 `referer` 来源页参数
- 每次连接从原始地址刷新短效 CDN 授权，失败后可更新链接并保留分块续传
- 可手动整合两个同文件任务，逐字节验证重复进度后保留较完整任务并转移可用链接
- 可在设置中持久化新任务的默认下载位置
- 标题栏显示当前版本，并提供版本、协议和项目地址信息
- 任务列表自动保存，程序重启后可以继续
- 自动避开同名文件，不覆盖已有文件
- 按天记录诊断日志，并对 URL 查询参数脱敏

## 使用

1. 粘贴以 `http://` 或 `https://` 开头的直接文件链接。
2. 选择保存文件夹和并发连接数。
3. 点击“添加下载”。
4. 若短效链接过期，选择原任务，在输入框粘贴网站新生成的地址，再点击链条图标继续。
5. 若重复添加了同一文件，按住 `Ctrl` 选中两个任务并点击整合图标。程序只在较完整任务已包含另一任务的全部进度时整合；为保护数据，被移除任务的临时分块不会自动删除。
6. 点击窗口右上角的齿轮可修改默认下载位置；按 `Ctrl+,` 也可打开设置。

使用以下命令生成 Windows x64 单文件发布版：

```powershell
dotnet publish .\BigFileDownloader.csproj -p:PublishProfile=win-x64
```

可执行文件位于 `Release/downloader-{version}.exe`，其中版本号读取自 [`VERSION`](VERSION)。

## 版本约定

当前版本记录在 [`VERSION`](VERSION) 中，初始版本为 `0.0.10`。版本格式为 `x.x.xx`，末段从 `10` 递增到 `99`；继续递增时中间位进一并将末段重置为 `10`，例如 `1.1.99` 的下一个版本是 `1.2.10`。

## 诊断日志

日志保存在 `%LocalAppData%\downloader\logs`，文件名为 `downloader-yyyyMMdd.log`。工具栏中的文档图标可以直接打开当天日志。日志不会记录 URL 查询参数，避免暴露临时 CDN 签名。

## 限制

- 当前版本不读取浏览器 Cookie，因此需要账号登录后才能访问的链接可能会返回 401 或 403。
- 原始下载地址本身已过期时，软件无法自行登录网站生成新地址，但更新任务链接后可以复用已有分块。
- 网盘分享页面、视频播放页面和带 DRM 的媒体不是直接文件链接，不能由本工具解析。
- 只有服务器支持 HTTP Range 时才可真正断点续传；否则继续任务会从头下载。
